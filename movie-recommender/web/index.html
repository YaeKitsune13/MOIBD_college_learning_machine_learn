Как пользоваться приложением

Переключайте вкладки сверху, чтобы протестировать все алгоритмы из Технического Задания. Нажимайте на звёздочки (1–5 ★) на любой карточке — оценка мгновенно сохранится в базу данных SQLite, а рекомендации пересчитаются.

Команды API

  • GET /api/movies/top — Топ-10 популярных фильмов (формула Байеса).
  • GET /api/users/:id/collaborative — Коллаборативная фильтрация по пользователям (User-Based KNN).
  • GET /api/movies/:id/collaborative — Коллаборативная фильтрация по фильмам (Item-Based CF).
  • GET /api/movies/:id/content — Рекомендации по контенту (сходство жанров).
  • GET /api/users/:id/personal — Персональные рекомендации (профиль вкусов).
  • POST /api/ratings — Сохранение оценки фильма в БД.

Параметры алгоритмов (кнопка «⚙ Параметры»)

  • limit — количество выводимых фильмов (по умолчанию 10).
  • k — число ближайших соседей для KNN (по умолчанию 30).
  • min_sim — минимальный порог косинусного сходства (0.15).
  • min_votes — минимум общих оценок для учёта фильма (2).
  • bayes_m — коэффициент сглаживания Байеса (20).
