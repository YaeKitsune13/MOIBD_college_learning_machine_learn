Параметры модели:

1. Коллаборативная фильтрация (User-Based KNN)

Поиск похожих пользователей по матрице оценок (инвертированный индекс + косинусная мера)
Режим «Холодного старта»: у выбранного пользователя 0 оценок. Выведен глобальный топ популярных фильмов. Поставьте оценку любому фильму звёздочками, и алгоритмы мгновенно пересчитают персональную выдачу!

2. Рекомендации пользователю (по его собственным оценкам)

Векторная модель предпочтений пользователя на основе высоко оцененных им жанров и рейтинга фильмов

3. Прогнозирование фильмов по контенту (Content-Based)

Косинусное сходство нормализованных векторов жанров относительно выбранного фильма

4. Топ популярных фильмов

Взвешенная формула Байеса (IMDB Weighted Rating) по всей базе данных

Справка по функционалу и параметрам системы

1. Назначение и архитектура

Приложение реализует гибридную рекомендательную систему фильмов на основе очищенного датасета MovieLens. Все вычисления выполняются в оперативной памяти (RAM) с использованием предрасчитанных L2-норм и инвертированного индекса.

2. Описание алгоритмов (Пункт 4 ТЗ)

  • Топ популярных фильмов: рассчитывается по формуле Байесовского среднего $WR = \frac{v}{v+m}R + \frac{m}{v+m}C$, где $R$ — средний рейтинг фильма, $v$ — число оценок, $m$ — минимальный порог оценок, $C$ — средняя оценка по всей базе. Это защищает топ от фильмов с одной оценкой 5.0.
  • Коллаборативная фильтрация (User-Based KNN): находит $K$ наиболее близких по вкусам пользователей с помощью косинусного сходства векторов оценок и прогнозирует рейтинг непросмотренных фильмов как средневзвешенное оценок соседей.
  • Рекомендации пользователю по его оценкам: формирует персональный профиль предпочтений пользователя (взвешенный вектор жанров на основе выставленных им оценок) и подбирает фильмы с максимальным сходством.
  • Прогнозирование по контенту (Content-Based): переводит жанры каждого фильма в бинарный вектор признаков и находит ближайшие фильмы по косинусной мере сходства.

3. Настраиваемые параметры модели

  • Кол-во (Limit): количество возвращаемых рекомендаций в каждом блоке (по умолчанию 10).
  • Соседей KNN (K): размер окрестности самых похожих пользователей при коллаборативной фильтрации (по умолчанию 30).
  • Мин. сходство (Min Sim): порог отсечения косинусной близости (от 0.05 до 0.95, по умолчанию 0.15).
  • Мин. голосов (Min Votes): минимальное число соседей, оценивших фильм-кандидат, необходимое для включения фильма в прогноз (по умолчанию 2).
  • Сглаживание Байеса (m): вес априорного среднего рейтинга при расчете топа популярных фильмов (по умолчанию 20).

4. Интерактивная работа и «Холодный старт»

Нажмите «+ Новый профиль» в верхней панели, чтобы создать нового пользователя с 0 оценок. Система автоматически распознает проблему холодного старта и предложит глобальный топ. Поставьте оценки (1–5 ★) на любых карточках фильмов — индекс обновится в реальном времени без перезагрузки базы.
