# 🏢 Прогнозирование стоимости недвижимости (Machine Learning)

Учебный исследовательский проект по построению и валидации моделей регрессии для оценки рыночной стоимости объектов недвижимости (в турецких лирах, TRY) по их характеристикам.

- **Выполнил:** Хабибуллин Артём Альбертович
- **Группа:** 23П-4
- **Основной блокнот:** `real_estate_homework.ipynb`

---

## 📌 Описание задачи и данных

Цель работы — построить предсказательный пайплайн, способный с высокой точностью оценивать стоимость аренды и продажи недвижимости на основе табличных признаков.

1. **`real_estate_data.csv`** — обучающая выборка (~400 000 сырых записей).
2. **`test_real_estate_samples.csv`** — контрольная выборка из 20 объектов для финальной оценки.
3. **`result_real_estate_samples.csv`** — выходной файл с исходными данными, персональными метаданными студента, расчётом метрик и колонкой `predicted_price`.

---

## 🛠 Методология и этапы пайплайна

### 1. Очистка и фильтрация данных

- **Предотвращение утечки данных (Data Leakage):** Проверка и удаление из обучающего набора строк, совпадающих с объектами контрольного теста по `id`.
- **Фильтрация шума:** Отсечение валют, отличных от TRY (EUR, USD, GBP), и некорректных типов сделок (оставлены `1` — продажа и `2` — аренда).
- **Борьба с аномалиями (Винзоризация):** Цены обрезаются по 1-му и 99-му квантилям раздельно для продажи и аренды. Признак площади логарифмируется (`np.log1p`).

### 2. Инженерия признаков (Feature Engineering)

- **Парсинг формул комнат:** Разделение формата вида `3 + 1` на количество спален (`rooms`) и гостиных (`halls`).
- **Извлечение числовых диапазонов:** Очистка строковых полей `building_age`, `floor_no`, `total_floor_count` от текста с вычислением среднего значения для диапазонов.
- **Географическая иерархия:** Выделение уровней `Город / Район / Микрорайон`.
- **Target Encoding:** Применение кросс-валидационного целевого кодирования (`TargetEncoder`) для локаций с высокой мощностью категорий.

### 3. Сравнительный анализ 7 моделей регрессии

Качество моделей оценивалось на стратифицированной валидационной выборке (20%) по метрикам **R²**, **MAE** и **RMSE (log)**:

| Модель                | Архитектура        | Особенности                                                            |
| :-------------------- | :----------------- | :--------------------------------------------------------------------- |
| **Ridge**             | Линейная           | L2-регуляризованная линейная модель                                    |
| **Decision Tree**     | Древовидная        | Базовое дерево решений с ограничением глубины                          |
| **Random Forest**     | Ансамбль (Бэггинг) | Случайный лес независимых деревьев                                     |
| **Extra Trees**       | Ансамбль (Бэггинг) | Экстремально рандомизированные деревья                                 |
| **Bagging**           | Ансамбль (Бэггинг) | Бэггинг-ансамбль над неглубокими деревьями                             |
| **AdaBoost**          | Ансамбль (Бустинг) | Последовательный адаптивный бустинг                                    |
| **Gradient Boosting** | Ансамбль (Бустинг) | `HistGradientBoostingRegressor` (наилучший баланс точности и скорости) |

> **Победитель:** Модель `HistGradientBoostingRegressor` показала минимальную ошибку в логарифмической шкале и максимальный коэффициент детерминации $R^2$.

### 4. Верификация расчёта метрик

В соответствии с требованиями к сдаче работы, расчёт метрик на контрольных 20 объектах реализован двумя независимыми способами:

1. **Вручную** (по математическим определениям формул $MAE = \frac{1}{n}\sum |y - \hat{y}|$, $RMSE = \sqrt{\frac{1}{n}\sum (y - \hat{y})^2}$ и $R^2 = 1 - \frac{SS_{res}}{SS_{tot}}$).
2. **Через библиотеку `scikit-learn`** (`mean_absolute_error`, `root_mean_squared_error`, `r2_score`).

Оба метода выдают идентичный результат с расхождением менее $10^{-6}$.
